# What every repository's CLAUDE.md should contain

Date: 2026-11-11 18:30:58 UTC

Added `plan.md` section 1.14 listing what the `CLAUDE.md` of every service repository and of the frontend repository should contain when it is initialized: purpose and place, link to `general`, the required sync rule with the changelog (with the suggested text and the "Last checked general changelog entry" line), contracts, stack and conventions, data, events, commands, git and pull requests, and rules for Claude. The frontend uses a subset. The suggested sync text moved from `CLAUDE.md` of `general` into this section, and `CLAUDE.md` of `general` now points to it, so there is one copy. Service repositories should create or update their `CLAUDE.md` from this section.
