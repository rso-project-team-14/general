# Branch naming convention

Date: 2026-11-11 19:41:43 UTC

Added the branch naming convention defined in a comment on issue #5 to `plan.md` section 1.13: `<initials>/<type>-<descriptive-name>`, where the initials are the first letter of the first name and of the surname, the type is `feat`, `fix`, and so on, and the descriptive name says what the branch is for. Removed it from the list of things still to be agreed in #5. Item 9 of the `CLAUDE.md` contents in section 1.14 now refers to it. Pull request and review rules, commit format, and the promotion approval remain open.
