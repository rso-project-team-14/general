# Other repositories sync by the hash on line 3, not by the changelog

Date: 2026-11-11 20:00:32 UTC

Redesigned how the other repositories detect changes. The changelog is now only a historical record for people, and for agents that need to understand why a change was made. It is not read to detect updates. Instead, every repository's `CLAUDE.md` lists the files in `general` it depends on (`plan.md`, the API contracts it depends on, the stage document it implements), each with a link and the hash recorded when the file was last read in full. Before implementing a feature, the agent reads only line 3 of each file, compares the hash, and re-reads the file only if the hash differs. Updated `plan.md` section 1.14 (item 3 and the suggested text, which replaces the "Last checked general changelog entry" text) and the layout comment in 1.4, and `CLAUDE.md` (what belongs here, "Document hashes", "Changelog", and "For the other repositories"). Earlier changelog entries that describe the old changelog-based sync are historical and unchanged.
