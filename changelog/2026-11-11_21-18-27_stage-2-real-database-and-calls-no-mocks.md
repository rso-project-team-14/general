# Stage 2 uses a real database and real calls, with no mocks

Date: 2026-11-11 21:18:27 UTC

Stage 1 has no tests about databases, because it has no database. Stage 2 no longer mocks the database or the client: the tests use the real `store` against a real database and the real `client` to make a real call, so `make test` needs them to be reachable, and the readiness test checks both a reachable database and an address where there is none. Added a "Who does what" section to `docs/stages/stage-2-database-and-calls.md`, the same split as in Stage 1: agents write the code and the tests, and the team sets up and manages the real (managed) databases and does the deployment, so an agent does not create or change databases or cloud resources. The checklist is split the same way. Replaced the mock text in Stage 2 that was moved there in an earlier entry. Fixed the definition of done in `plan.md` section 2.4, which asked for integration tests of the database layer in every stage: tests now apply as far as the stage includes them, and the OpenAPI line applies where a service has a spec. This addresses the second point of the review of the branch. This follows a decision made in conversation.
